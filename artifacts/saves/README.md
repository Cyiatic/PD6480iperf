# Dark — 100% stock-format save (v1)

`Perfect-Dark-Dark-100-stock-v1.eep` is a **2048-byte N64 EEPROM** image for
Perfect Dark USA/NTSC v1.1. It is a normal cartridge save, not a save state or
a ROM patch. It also targets the merged ROM's unchanged stock save format.

## Contents

- Solo agent named **Dark**: all 21 missions on all three difficulties (63/63).
- All 20 co-op missions (17 campaign + three specials), all difficulties (60/60).
  The Duel is solo-only, so its co-op bits remain clear.
- All timed/completion cheats and eight classic weapon cheats unlocked.
  Cheats are not enabled: the stock game clears enabled cheats when loading an agent.
- All 32 stock NTSC-final firing-range gold medals, weapons found,
  device/hologram training, and CI tour complete. The unused 33rd score is zero.
- All 30 Combat Simulator challenges complete for one through four players.
- Combat Simulator player also named **Dark**, with **Perfect:1** rank and all challenges complete.
- Stock 1.1 controls, default volumes/stereo, full-screen 4:3, **Hi-Res OFF**.
- Alternative title unlocked but disabled, so the normal title remains selected.
- Other agent/player/setup slots remain empty; swap slots are retained.

This is generated completion data. Mission times, playtime, and multiplayer
statistics are synthetic, not player-earned records. No GameShark codes or
PC-port-only features are needed. Transfer Pak use and unused flags are not
falsely enabled. Non-completion mission-route choices retain their default values.

## Import on EverDrive (including EverDrive used in Analogue 3D)

1. Back up the existing save before importing. This image replaces the whole
   Perfect Dark cartridge save, not just one agent slot.
2. Use the same ROM base filename for the save, changing only the extension to
   `.eep`. Example: `My-PD-ROM.z64` uses `My-PD-ROM.eep`.
3. Put it in the save location your EverDrive firmware already uses for that
   ROM. Firmware layouts vary; the older X7 manual calls this `ED64/save`.
   Prefer the actual location of a save generated by your installed firmware.
4. If the cart continues to show its previous save, select the intended PD ROM
   first, return to the EverDrive menu, then select this `.eep` and use
   **Copy File To RAM**. Launch the already-selected game with **Start**.
   Do not copy save data to RAM for an unrelated selected game.
5. Load **Dark** in the game's normal agent menu. Use the **Dark** player file
   separately if desired in Combat Simulator.

The required cartridge save type is **EEPROM 16Kbit**, not 16KB. This file must
not be byte-swapped or converted into a controller-pak `.mpk`. It is not an
Analogue Memories save state. The save does not fix the ROM's unresolved
Hi-Res-toggle freeze; leave that option off in the current candidates.

The [official EverDrive X7 manual](https://krikzz.com/pub/support/everdrive-64/x-series/everdrive-64-manual.pdf)
documents save-RAM copying and EEPROM16K support. No installed saves were
overwritten while producing this package.

The generator is `tools/saves/make_dark_save.py` in the repository. It uses the
stock [Perfect Dark decomp](https://github.com/n64decomp/perfect_dark), principally
`gamefile.c`, `bossfile.c`, `pak.c`, `crc.c`, `training.c`, `cheats.c`, and
`mplayer/mplayer.c`. It requires neither copyrighted ROM data nor an existing save.

```powershell
python tools/saves/make_dark_save.py new-dark-save.eep
python -m unittest discover -s tools/saves -v
```

Optional independent C++ check (point the include/source arguments to an
unmodified PDSaveEditor checkout):

```text
g++ -std=c++17 -O2 -I ../pd-save-editor/src/Game tools/saves/check_dark_save.cpp ../pd-save-editor/src/Game/SaveData.cpp -o check-dark-save
check-dark-save artifacts/saves/Perfect-Dark-Dark-100-stock-v1.eep
```

PDSaveEditor's diagnostic table labels unused-body checksum markers as `BAD`;
the stock format intentionally stores `FFFF-FFFF` for unoccupied records.
Every occupied record in this image passes both header and body checksums.
